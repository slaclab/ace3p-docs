    Modules¶

    ACE3P is a family of solvers that share one mesh format, one input syntax, and one post-processing toolchain. Each module addresses a different physics regime.

    Module Guide Status of this documentation
    Omega3P User guide and tutorials Complete: concepts, three tutorials, post-processing
    S3P User guide and tutorials Complete: concepts, input blocks, output files, three tutorials
    T3P User guide and tutorials Complete: wakefields, port excitation, moving window, SIBC, five tutorials
    Track3P User guide and tutorials Complete: multipacting and dark current, six tutorials, S3DF rerun
    Pic3P User guide and tutorial Complete: self-consistent PIC, LCLS gun tutorial
    TEM3P User guide and tutorials Complete: thermal, elastic, LF detuning, mechanical eigenmodes, four tutorials
    Gun3P User guide and tutorial Complete: DC gun iteration, sheet beam gun tutorial with MICHELLE comparison

    Which module do I need?¶

    flowchart TD
    Q1{What do you want?} 
    Q1 -->|Resonant frequencies, Q, R/Q, field patterns| O[Omega3P]
    Q1 -->|Transmission and reflection vs frequency| S[S3P]
    Q1 -->|Wakefields or transient beam-driven fields| T[T3P]
    Q1 -->|Multipacting or dark current| TR[Track3P]
    Q1 -->|Self-consistent beam with space charge| P[Pic3P]
    Q1 -->|Heating, stress, or frequency shift from deformation| TE[TEM3P]
    Q1 -->|Electron gun or DC beam optics| G[Gun3P]

    Several modules chain together. Track3P reads the mode fields that Omega3P produces. TEM3P reads Omega3P or S3P fields as a heat source. The workflow assistant page shows how such chains are automated.
