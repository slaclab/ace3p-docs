# ACE3P GUI

The ACE3P GUI is a desktop application for preparing input files and launching ACE3P jobs without editing text files by hand. Its first release is version 1.4.15.

## Availability

=== "Perlmutter (Linux)"

    The compiled executable is installed in the ACE3P project directory:

    ```bash
    /global/cfs/cdirs/ace3p/gui/ACE3P-GUI-v1.4.15-linux-x86_64/ACE3P-GUI
    ```

    Connect to Perlmutter through [ThinLinc](https://docs.nersc.gov/connect/nx/) so that a graphical desktop is available, open a terminal, and launch the executable from it.

=== "Windows"

    A Windows build is distributed through SLAC SharePoint. Ask the ACE3P team for the current download link.
