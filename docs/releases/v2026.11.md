## Track3P

- Step loop up to 15x faster on large meshes with identical results: `Domain.Bins` omitted (or `<= 0`) now picks about one element per bin along the longest axis instead of 64, and particle localization starts from the previous element and its face neighbours before the grid. Inputs that carry `Bins: 256` should drop that line. KEK 56-cell field emission, 30 RF cycles, one node: 1794 s to 122 s. (PR #239)
- Startup: DOF numbering skipped for tracking, field-emission faces owned per rank instead of sampled on every rank, one shared vertex-field pass for `InterpolationMethod: Linear`. The loop timing report is always printed on rank 0. See the Track3P page "Faster particle localization and startup".

## Gun3P

- `gun3pOutputConverter` (and `kly3pOutputConverter`): the structured-grid E-field export accepts optional `XRange`, `YRange`, `ZRange` in `Outputs` to set the grid extent per axis; omitted axes keep the mesh bounding box. Fixes the `Ny` default being written to `nx`. See the Gun3P page "Structured-grid E-field export on a user-chosen region". (PR #240)
